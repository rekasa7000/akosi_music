# Shared

Not yet scaffolded.

Framework-agnostic types, constants, and validation schemas shared
between the web app and API (e.g. tap-verify response shapes, card/
track/user types, status enums). No UI components, no database
client, no cryptographic logic — those stay out of this package on
purpose (see conventions doc).
